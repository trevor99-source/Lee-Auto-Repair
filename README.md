# Lee’s Auto Repair website

A simple static website. All files sit in one folder, with no sub-folders.

## Files
- `index.html` Home
- `services.html` Services and car list
- `work.html` Our work and reviews
- `find-us.html` Where to find us
- `emergency.html` Emergency callout
- `contact.html` Contact us (the form opens WhatsApp with the message filled in)
- `style.css` the design, `main.js` the menu, car search and form
- `logo.jpg`, `favicon.png` images
- `404.html`, `robots.txt`, `.nojekyll` GitHub Pages helpers

## Put it on GitHub Pages
1. Create a new repository on github.com.
2. Upload all the files (select them all and drag them in). `index.html` must be at the top level.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then Save.
4. After a minute the site is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.
